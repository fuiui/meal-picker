# What to Eat — 今天吃什么

这是 Web Technologies 个人项目，独立于旁边的课堂网站 `my-site`。

当前进度：**前三部分已完成：选题规划、初始封面、推荐页 HTML 骨架**。推荐页选择框可操作，但推荐按钮暂时禁用；其他三个正式页面和推荐逻辑尚未实现。各阶段保存在本地 Git，未设置远程仓库、未上传。

## 查看本阶段结果

- 打开 `pick.html` 查看第三部分推荐页结构；当前使用浏览器默认样式。
- 阅读 `docs/03-html-structure.md` 对照学习标签；验证结果在 `docs/stage-03-check.json`。

- 打开 `design/preview.html` 看第二部分封面预览、缩略图和设计说明。
- 打开 `design/cover.html` 看可编辑的封面设计。
- 打开 `design/og-image-v1.jpg` 看保留的初稿；`images/og-image.jpg` 是当前封面。
- 阅读 `docs/01-project-plan.md`：四个页面、选题理由、草图和验收标准。
- 阅读 `docs/learning-log.md`：实际完成事项、待学习问题与后续阶段。
- 阅读 `docs/project-brief.md`：可用于解释第一部分的英文项目简报。
- 阅读 `docs/02-cover-design.md`：第二部分交付与代码知识；验证结果在 `docs/stage-02-check.json`。
- 在项目文件夹运行 `git log --oneline` 查看本地记录，运行 `git status` 查看尚未提交的修改。

后续页面使用英文，解释文档和关键代码注释使用中文，便于学习和答辩。AI 协助制作，内容需要学生审阅、理解并修改成自己认可的表达；不能把文件已生成视作已经学会。
