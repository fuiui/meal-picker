# 第二部分：初始封面

依据：Your Project 课件要求先制作 1200 × 630 的 JPG/PNG 封面，小于 100 KB，包含大标题、一句简介和一个视觉元素。课件允许使用 HTML/CSS 制作并截图导出，并要求保留初稿用于之后对比。

原文：https://webtech.landrock.io/slides/project.html

## 本部分交付

- `design/preview.html`：可直接双击打开的中文预览，包含大图、300 像素缩略图、配色和说明；不是正式网站页面。
- `design/cover.html`：固定 1200 × 630 的可编辑 HTML/CSS/SVG 画布。
- `images/og-image.jpg`：本阶段确认使用的初始封面，后续用于分享和课程平台。
- `design/og-image-v1.jpg`：保留早前初稿，不覆盖；本次沿用其构图，不为制造版本差异而重画。
- `docs/stage-02-check.json`：本阶段实际验证结果。

## 设计选择

标题 **What to Eat** 为三个英文单词，契合项目名称长度要求。

简介：A simple meal picker helping students choose what to eat by budget and taste.（14 词，与第一部分一致。）

奶油色背景让封面有菜单的感觉；深绿色保证主要文字清晰；橘红色用于强调 Eat。标题与简介靠左，餐盘插图靠右，避免叠在复杂图片上。主要内容四周留白，方便缩略展示；不能保证所有平台的任意裁切均完整显示。

封面主要使用本机字体，不加载外部网络资源。插图由 SVG 圆形、椭圆和路径组成，没有使用第三方照片，由 Codex 辅助制作。用户仍需理解并认可标题、简介和设计选择。

## 你要能解释的知识

| 可能问到的问题 | 理解重点 |
| --- | --- |
| 封面有什么用？ | 别人分享网站链接时的预览图，也是课程平台的项目封面。 |
| 和 favicon 有什么区别？ | 封面是横向分享图片；favicon 是浏览器标签上的小方形图标，后续制作。 |
| 为什么有 HTML 和 JPG 两个文件？ | HTML 是可修改的设计源文件，JPG 是导出的交付图片。 |
| Flexbox 在这里做什么？ | 把文字和餐盘放在同一行，并设置它们之间的间距。 |
| SVG 是什么？ | 用文本描述图形的矢量格式；这里用基本图形组合餐盘。 |
| 为什么没有分享链接标签？ | 目前还没有真实上线地址，后续页面阶段再接入，不能填假地址。 |

## 验证边界

检查导出尺寸、实际字节数、文字区域是否超出画布、浏览器错误和预览页在电脑/手机宽度下的显示。检查原始 v1 文件哈希未变化。大图与缩略图需要视觉检查。

不将此封面预览算作四个正式页面之一。本部分不制作网站功能，不提交 Git、不上传。下一部分制作推荐页 HTML 骨架。
