# 第六部分：统一样式与响应式布局

打开 `index.html` 查看本阶段结果，仍然支持本地双击，无需网络或构建工具。

## 改了什么

四页改用同一个 `style.css`。采用第二部分确定的奶油色背景、深绿色文字、橘红色按钮；标题用 Georgia，正文用系统字体，无外部字体请求。

- 首页：大标题、食物插图、醒目的推荐入口；使用流程桌面三列、手机单列。
- 推荐页：电脑左右两栏，左边选择条件，右边显示结果；600 像素及以下改为上下排列。
- 美食清单：大屏三列、900 像素及以下两列、600 像素及以下一列。卡片统一边框、间距与图像尺寸。
- 关于页：限制正文宽度，分节并增加段落间距，避免长行难读。
- 导航：当前页深绿色；手机保持四个选项直接可见，不添加需要额外 JavaScript 的折叠菜单。
- 键盘：Tab 聚焦显示明显轮廓，“Skip to main content”聚焦后显示；可跳过导航直接进入表单。

首页原本使用带文字的分享封面作为主图，现在使用本地饭碗 SVG，避免首页标题与图片中的标题重复。原分享封面仍保留，未覆盖。第五部分的 `media.css` 也保留为历史文件，正式四页不再加载它。

## 代码怎么讲

| CSS | 含义 |
| --- | --- |
| `:root` 与 `var(--ink)` | 集中定义颜色，多个页面共用，避免逐个修改颜色代码。 |
| `box-sizing: border-box` | 元素宽度包含内边距和边框，控制尺寸更直接。 |
| `display: flex` | 导航、按钮组等沿一个方向排列。 |
| `display: grid` | 首页、推荐区域和卡片列表按行列布局。 |
| `repeat(3, minmax(0, 1fr))` | 三列平均分配空间，并允许内容在列内收缩。 |
| `gap` | 设置列和元素之间的间隔。 |
| `@media (max-width: 600px)` | 屏幕窄到指定宽度时，覆盖桌面布局规则。 |
| `clamp()` | 字号随屏幕变化，但保持在最小和最大值之间。 |
| `max-width: 100%; height: auto` | 图片不超出容器，并保持长宽比例。 |
| `:focus-visible` | 键盘聚焦时给用户明确的位置提示。 |

样式改变外观，不改变 HTML 的意义。推荐仍然依靠原来的 JavaScript，食物数据、价格与随机逻辑未改动。
