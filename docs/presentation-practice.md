# 演示与问答练习

这是练习提纲，不是现场照读稿。老师要求直接展示网站、用自己的话讲，三分钟演示加两分钟问答，不使用 PPT、不读手机或纸稿。

## 三分钟路线

| 时间 | 打开哪里、做什么 | 要讲清的意思 |
| --- | --- | --- |
| 0:00–0:25 | 首页 | 给拿不定吃什么、有预算偏好的学生使用；四页分工。 |
| 0:25–1:10 | Pick a Meal，选择不限条件，点击推荐；再选 ¥15 和 Non-spicy | 先筛选再随机，结果不会超预算。 |
| 1:10–1:35 | ¥15 + Spicy，然后改为 ¥25 | 无结果时给提示；只有一个候选时反复推荐同一道是合理行为。 |
| 1:35–2:00 | Meal Collection | 12 道菜单与推荐共用数据；价格是示例，图片是类型插图。 |
| 2:00–2:30 | 缩窄浏览器或开启手机预览 | 清单三列变一列，推荐左右变上下，导航一直能看到。 |
| 2:30–3:00 | About | 解释内容来源、AI 辅助、无数据库与不会下单；下一步可以改善什么。 |

最终现场应从课程平台的项目条目进入真实上线地址。当前未上线，练习可双击 index.html；正式展示前准备 VS Code Live Server 作为断网备用。

## 看代码时怎么回答

| 问题 | 文件与理解重点 |
| --- | --- |
| HTML、CSS、JavaScript 各做什么？ | HTML 放结构，style.css 控制外观，JS 读取条件并更新结果。 |
| 食物在哪里？ | meals.js 中的数组，每道食物是一个对象；name、price、taste、description 等为属性。 |
| 为什么清单和推荐价格一致？ | 两页都读取 meals.js，卡片都调用 meal-card.js，不维护两套数据。 |
| 怎么筛选？ | pick.js 的 getCandidates：预算条件和口味条件用 && 组合，filter 返回符合条件的新数组。 |
| 为什么 Number(budget)？ | select.value 返回字符串，比较金额时把它转成数字。 |
| 为什么用 <=？ | 恰好等于预算也算匹配。 |
| 如何随机？ | Math.random() 乘候选数量再 Math.floor()，得到有效下标 0 到 length-1。 |
| 没有候选怎么办？ | 先检查 length 是否为零，提示后 return，不访问不存在的数据。 |
| 为什么结果会重复？ | 每次独立随机；没有做排除上一道的功能。 |
| 怎么响应点击？ | 表单监听 submit；preventDefault 阻止跳转；同样支持键盘提交。 |
| 改条件后为什么清空？ | change 事件调用 resetResult，防止旧食物与新条件不符。 |
| textContent 是什么？ | 将值作为文字插入页面，不把食物文本当 HTML 解析。 |
| 为什么手机变单列？ | style.css 的 @media 在 600px 及以下覆盖网格列数。 |
| 为什么不用数据库或框架？ | 固定小菜单与本地筛选足够，不需要保存账号和订单，代码更容易理解。 |
| 图标与封面有什么区别？ | favicon 是标签上的小方图，app icon 是手机主屏图标，OG 封面是分享链接的横向预览图。 |
| 使用了 AI 吗？ | 如实说明 Codex 辅助的规划、代码、插图和文字，以及自己已检查、理解的部分。 |

## 不看答案自测

1. 指出预算框的 label、id 和 JavaScript 读取位置。
2. 用纸笔演示 3 个候选时如何得到随机下标。
3. 修改一个示例价格，解释两页为何会同时变化；练习后恢复原值。
4. 说明刷新后为什么失去之前选择。
5. 解释两个媒体查询为何分别选 900px 和 600px（中屏两列、小屏一列）。
