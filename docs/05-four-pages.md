# 第五部分：把一个推荐页变成四页网站

## 从哪里打开

双击根目录的 `index.html`，从导航进入推荐页、美食清单和关于页面。四个 HTML 文件以及它们使用的脚本、图片必须一起保留。本阶段不依赖网络，双击打开即可。

## 本次增加的内容

| 页面 | 本阶段完成的内容 |
| --- | --- |
| Home | 网站用途、封面图、三步使用说明、推荐和清单入口、示例价格说明 |
| Pick a Meal | 保留原来的筛选与随机逻辑；导航补齐；结果卡片增加类型示意图 |
| Meal Collection | 显示同一份菜单中的全部 12 道食物，包含名称、示例价格、口味、描述和插图 |
| About | 受众、筛选与随机原理、重复规则、刷新行为、内容和图形来源、AI 辅助及功能局限 |

四页都有唯一主标题、独立页面标题与描述、导航当前页标记、跳过导航链接和页脚。导航不再包含 coming soon；所有链接都指向已存在的文件或章节。

## 数据怎么流动

```text
meals.js：同一份 12 道菜单 + 每道食物的图片路径和替代文字
    ├─ collection.js：遍历全部食物 → createMealCard(meal, 'h2') → 清单页
    └─ pick.js：筛选并随机选一道 → createMealCard(meal, 'h3') → 推荐结果

meal-card.js：公共卡片函数，定义图片、名字、价格、口味和描述的显示方式
```

因此改一道菜的价格只改 `meals.js`，清单和推荐都会更新，不用手写两份菜单。图片按类别映射，使用 `mealIllustrations[meal.id] || 'rice'`：查到指定类型就使用，否则使用饭碗类型。随后给每个对象补充 `image` 和 `imageAlt` 属性。

## 为什么只有四张插图

本次新增本地 SVG：饭碗、面碗、饺子、混合锅。它们是类型示意图，多道饭类食物会共享饭碗图；不是十二道菜的实拍照片。清单、推荐页和关于页都对此作了说明。所有图形使用圆、椭圆和路径绘制，由 Codex 辅助制作，没有引用第三方照片。

`imageAlt` 为辅助阅读工具说明图片含义。图片写明宽高；`media.css` 仅用 `max-width: 100%` 和 `height: auto` 防止图片撑宽手机页面，不是第六部分的完整样式。

## 这次要会解释的代码

- `<a href="meals.html">`：相对路径，跳到同文件夹里的清单页。
- `about.html#sources`：跳到关于页里 `id="sources"` 的部分。
- `aria-current="page"`：指出当前页面的导航项。
- `forEach()`：对数组中的每道食物依次执行函数，生成卡片。
- `createMealCard()`：把重复的显示逻辑写成一个公共函数。
- 清单用 `h2`，推荐结果用 `h3`：推荐结果区已有 `h2`，所以菜名在其下一层。
- `append()`：将生成的元素加入页面；`textContent` 只填文字，不执行 HTML。
- 脚本顺序：先菜单，再公共卡片函数，最后页面逻辑，避免调用尚未定义的数据或函数。

导航暂时直接写在四个 HTML 中，使 JavaScript 关闭时仍然可以切换页面，也保持本地双击使用简单。更改导航名称时需同步四页；本阶段检查了四页一致。清单和推荐功能需要 JavaScript；无 JavaScript 时清单显示明确说明，首页、关于页和导航仍可阅读。

## 自己操作检查

1. 从首页点击推荐，按预算和口味获取一道食物。
2. 打开清单，找到这道食物，比较价格、描述与图片。
3. 从清单点击来源说明，应跳到 About 的来源章节。
4. 通过导航依次走遍四页，查看当前页标记。
5. 回推荐页试 ¥15 + Spicy，应提示无匹配；改为 ¥25 后会推荐 Mapo tofu rice。
